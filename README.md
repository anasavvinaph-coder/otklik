# Отклик · GitHub Pages, поиск без платного ИИ

Это полностью статическая версия сайта: HTML + JS. Публикуется через GitHub Pages без сервера и без секретных ключей. **Ни владелец, ни посетители не расходуют токены OpenAI.**

Что происходит при поиске:
1. Примеры для четырёх тем (совесть, жизненный тупик, Париж, одиночество) содержат редакционные рекомендации с конкретными объяснениями.
2. Дополнительно браузер обращается напрямую к [Open Library Search](https://openlibrary.org/dev/docs/api/search) (книги) и поиску по статьям [Wikipedia / Wikimedia](https://www.mediawiki.org/wiki/API:Search) (фильмы и картины).
3. Новые результаты обозначены как «Каталог»: совпадение по тексту / ключевым словам не равно глубокому смысловому соответствию. Нельзя выдавать их за рекомендации ИИ.
4. После первой выдачи появляется поле «Уточнить»; работают фильтры категорий и ориентировочные уточнения.

**Ограничения:** нет общего поиска по миллионам текстов с пониманием смысловых связей. Некоторые постеры или обложки отсутствуют; доступность сторонних API зависит от сети, CORS, квот и правил использования. Поиск прямой из браузера не обеспечивает единый серверный кэш. Для точного смыслового поиска в будущем нужен либо редакционно размеченный каталог с офлайновыми эмбеддингами, либо ИИ-сервер с контролем расходов.

## Опубликовать на GitHub Pages

1. Создать новый **публичный** репозиторий с именем `otklik` на https://github.com/new (имя можно изменить).
2. Положить в корень `index.html`, `.nojekyll`, `README.md` (или загрузить этот архив через Add file → Upload files).
3. На странице репозитория открыть **Settings → Pages**.
4. В **Build and deployment** выбрать `Deploy from a branch`, затем `main` и `/ (root)`, нажать **Save**.
5. GitHub покажет точный адрес сайта на странице Settings → Pages. Обычно он имеет вид `https://<ваш-логин>.github.io/otklik/`. Не считайте адрес активным до публикации GitHub Pages.

Никаких `OPENAI_API_KEY`, `.env`, токенов TMDB и приватных настроек в этом репозитории нет. GitHub Pages не выполняет Python сервер (FastAPI): для ИИ-версии нужен отдельный хостинг.
